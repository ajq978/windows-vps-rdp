## Сколько человек может одновременно работать по RDP

Windows Server включает две лицензии для административного подключения по RDP. Всё, что сверх этого, требует пользовательских лицензий (CAL), и их объём согласуется отдельно — так этот вопрос сформулирован в документации ОБИТ. Hostkey отвечает на него мягче: возможность одновременного подключения нескольких пользователей зависит от лицензии и настроек сервера.

Практический вывод: один-два человека (администратор плюс бухгалтер, например) укладываются в штатные две сессии. С третьего одновременного пользователя начинается отдельная статья расходов, и она часто сопоставима со стоимостью самого сервера.

HostFinch показывает это через прайс: тариф USA-WIN-4 за $43.99/мес прямо помечен как Multi-user RDP на 5–10 пользователей, а дополнительная RDP-лицензия идёт строкой «по запросу». Формулировка честная — многопользовательский режим стоит других денег.

Считайте не «сколько стоит сервер», а «сколько стоит сервер плюс CAL на каждого, кто работает одновременно».

## Windows 10 или 11 в аренду не выдают

ОБИТ отвечает на этот вопрос однозначно: доступны только серверные редакции — Windows Server 2019, 2022 и 2025 Standard. Рег.облако работает на Windows Server 2022, Hostkey — на 2022 и 2025. Причина практическая: серверная версия рассчитана на одновременную работу нескольких пользователей, клиентская — нет.

Если в объявлении обещают «Windows 10 RDP», первым делом спросите, какая редакция и какая лицензия будет на сервере. Провайдеры, чьи страницы удалось проверить, выдают только Windows Server.
